- `npnqrzl` has 7 letters, the same length as the `academy` flag prefix. That fits a letter-for-letter substitution.

---

## 3. Step-by-Step Walkthrough

### Step 1: Understand ROT13

ROT13 shifts each letter 13 places forward in the alphabet and wraps around after `z`. The alphabet has 26 letters, so applying ROT13 twice gives back the original text. The same operation encodes and decodes.

```text
Plain:  a b c d e f g h i j k l m n o p q r s t u v w x y z
ROT13:  n o p q r s t u v w x y z a b c d e f g h i j k l m
```

For example, `n → a`, `p → c` and `q → d`, so `npnqrzl` decodes to `academy`.

### Step 2: Decode the ciphertext

You can decode it with `tr` in a terminal:

```bash
echo 'npnqrzl{abg_gbb_onq_bs_n_ceboyrz}' | tr 'A-Za-z' 'N-ZA-Mn-za-m'
```

Or open [CyberChef](https://gchq.github.io/CyberChef/), paste the ciphertext into the Input panel and add the **ROT13** operation.

### Step 3: Retrieve the flag

The output is the decoded flag in `academy{...}` format.

## 5. Key Takeaways

- ROT13 is a Caesar cipher with a fixed shift of 13. It has no key, so it only hides text and gives no security.
- Non-letter characters such as `{`, `}` and `_` pass through unchanged. This is why the flag format stays visible in the ciphertext.
- `tr 'A-Za-z' 'N-ZA-Mn-za-m'` is a quick one-line ROT13 decoder.
