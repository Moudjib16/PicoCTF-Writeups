## 1. Challenge Overview

The challenge asks to convert the decimal number `42` to binary.

**Objective:** Convert `42` from base 10 to base 2 using CyberChef.

---

## 2. Solution

### Step 1: Convert decimal to binary

Open [CyberChef](https://gchq.github.io/CyberChef/), enter `42` in the Input panel, and add the **To Binary** operation. Set the input format to decimal (base 10).

The binary result is:

```text
101010
```
