## 1. Challenge Overview

The challenge provides the Base64-encoded string `bDNhcm5fdGgzX3IwcDM1` and asks what it means.

**Objective:** Decode the provided string from Base64 using CyberChef.

---

## 2. Solution

### Step 1: Decode the Base64 input

Open [CyberChef](https://gchq.github.io/CyberChef/), paste `bDNhcm5fdGgzX3IwcDM1` into the Input panel, and add the **From Base64** operation.

The decoded text is:

```text
l3arn_th3_r0p35
```
